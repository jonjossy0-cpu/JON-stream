3. Acceptance rule

Compare the same stream with JON Stream's normal player at the same network speed. The future AI path can only be enabled if it shows measured visual improvement without increasing startup delay, buffering, audio/video sync errors, or device overheating. If unsupported or slower, normal playback remains the fallback.
