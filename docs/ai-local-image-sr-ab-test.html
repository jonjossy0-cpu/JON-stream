JON Stream — Local Image Super-Resolution A/B Test

An isolated image-only prototype for the ONNX Model Zoo ESPCN candidate. It never opens a stream and is not connected to JON Stream's player. Both the selected image and model are processed in this browser tab; this page does not intentionally upload them.

Experimental: This candidate uses a luminance-only model and 3× upscaling. It is not true 4K restoration, not video playback enhancement, and may introduce artifacts. Do not use the output as evidence that live-stream AI is active.

Expected SHA-256 (from the official model file listing): 85f36ff88cc504a24af5e0602148bc56a8aa09a58eca8c0da2756f3e8186035e. A different hash is rejected.

Known limitations
  • The reference preprocessing resizes to 224 × 224 and extracts Y from YCbCr. This prototype uses browser canvas scaling and standard RGB↔YCbCr formulas, which may not match the reference pipeline pixel-for-pixel.
  • Output chroma is resized with browser canvas smoothing, not a guaranteed Pillow bicubic implementation.
  • One still image does not test temporal flicker, frame latency, thermal throttling, memory stability, or live HLS compatibility.
  • Model hash verification protects against accidental file mismatch, but does not independently audit model licensing or provenance.
