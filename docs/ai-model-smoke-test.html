JON Stream — AI Model Smoke Test

Isolated experiment only. This page loads a model file you select from your device, creates a small zero-input tensor, and measures whether ONNX Runtime can initialize and execute it. It does not open a stream, upload frames, or connect to the production player.

Important: A successful smoke test is not proof of visual quality, real-time video speed, low memory use, or temporal stability. Do not use the results to claim AI enhancement is active.

The ONNX Runtime Web library is loaded from jsDelivr when you press Run; internet access is required for the library. Your selected model stays in this browser tab and is not uploaded to a server by this page.
